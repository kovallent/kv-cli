# KV001: missing contract parameter

Severity: set per parameter in the contract. In the default contract,
`target_environment` is an error and `dry_run` is a warning.

## What it catches

A governed function that does not declare a parameter the contract requires.
The function runs and passes its tests. In production it quietly uses
whatever the author's machine assumed, because nothing passes it the target
environment.

```python
def deploy_service(name):                 # KV001: no target_environment
    ...
```

## How to fix it

Declare the parameter, then pass it through from the call site:

```python
def deploy_service(name, target_environment: str = "dev", dry_run: bool = False):
    ...
```

`kv-cli fix` inserts the parameter with the annotation and default the
contract sets. It goes before `**kwargs` and keeps a multi-line signature's
layout. `fix` changes only the signature, so you still have to pass the real
value at each call site.

## Which functions are governed

A function is governed when it matches any `applies_to` rule:

- `name_patterns`, e.g. `deploy*`, `run_*`, `*_job`;
- `decorators`, e.g. `task`, `kovallent.task`;
- `all_functions: true`, which governs every function.

Each finding says which rule matched:
`in scope: name matches applies_to.name_patterns "deploy*"`.

A function is never governed when:

- its name matches `exempt_name_patterns` (`_*` and `test_*` by default),
  which is checked first;
- a framework owns its signature, for example dbt's `def model(dbt, session)`
  or Databricks' `@dlt.table`. Adding a parameter there would break the
  pipeline. `kv-cli frameworks` lists every owned signature.

Airflow's `@task` is governed but report-only. `fix` prints a `manual:` item
instead of inserting a default, because an inserted default would read
"dev" in every environment while looking correct.

## How to turn it off for a function

There is no per-line marker for KV001. Exempt the function by name instead:

```yaml
applies_to:
  exempt_name_patterns: ["_*", "test_*", "legacy_*"]
```

## Contract keys

`parameters`, `applies_to`, `frameworks`, `fix.insert_missing_parameters`
